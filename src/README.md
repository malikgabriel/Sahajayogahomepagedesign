# Site Web Sahaja Yoga France 🧘‍♀️

Un site web moderne et vibrant pour l'organisation de méditation Sahaja Yoga en France.

## 🎨 Design

Design inspiré de **Headspace** avec une identité visuelle moderne 2025 :
- **Palette de couleurs** : Coral (#FF6B6B), Turquoise (#4ECDC4), Jaune chaleureux (#FFD93D)
- **Style** : Formes organiques, coins arrondis (3rem), animations douces
- **Animations** : Blobs animés, effets de flottement, transitions fluides
- **Responsive** : Design mobile-first entièrement responsive
- **Photos** : Images professionnelles de personnes méditant dans des environnements modernes, élégants et accessibles (style Ralph Lauren)

## 📄 Structure des Pages

### Page d'accueil (`/`)
- Hero avec CTA principal
- Section À propos
- Proposition de valeur
- Aperçu des centres
- Témoignages
- Événements à venir
- CTA d'inscription finale

### Page Centres (`/centres`)
- Liste des centres par région
- Carte interactive (lien vers Sahaj Atlas)
- Informations pratiques (horaires, contacts)
- FAQ pour les nouveaux visiteurs

### Page À propos (`/about`)
**C'est quoi ?**
- Description de Sahaja Yoga
- Bienfaits de la méditation
- Base scientifique

**C'est où ?**
- Lieux de pratique
- Centres et événements

**C'est qui ?**
- Présentation de Shri Mataji (fondatrice)
- Lien vers World Foundation
- Témoignages des pratiquants (Yogis)

**Rayonnement International**
- Présence mondiale
- Liens vers sites internationaux
- Projets et partenariats

**Méditation pour les enfants**
- Programmes jeunesse
- Ateliers pour enfants
- Témoignages de parents

### Page Témoignages (`/testimonials`)
- Témoignages de pratiquants par catégorie
- Filtres : Transformation, Santé, Paix intérieure, Communauté
- Section podcasts et interviews
- Histoires vidéo inspirantes

### Page Événements (`/events`)
- Prochaines rencontres et ateliers
- Méditations guidées
- Festivals et salons
- Retraites week-end
- Système de réservation

### Page Contact (`/contact`)
- Formulaire de contact complet
- Informations de contact (email, téléphone)
- Liens vers réseaux sociaux
- Inscription newsletter

## 🌐 Réseaux Sociaux

Le site intègre des liens vers :
- **Facebook** : Actualités et événements
- **Instagram** : Photos et inspirations quotidiennes
- **YouTube** : Méditations guidées et interviews

## 🛠 Technologies

- **React** avec TypeScript
- **Tailwind CSS v4** avec design tokens personnalisés
- **Lucide Icons** pour les icônes
- **Système de routing** simple avec état local
- **Animations CSS** personnalisées

## 🚀 Navigation

Le site utilise un système de navigation par état :
- Navigation depuis le header
- Navigation depuis le footer
- Smooth scrolling pour les sections de la page d'accueil
- Active state pour indiquer la page actuelle
